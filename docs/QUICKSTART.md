# 使用流程

## 第一次设置（约 10 分钟，只做一次）

### 1. 启动

```bash
git clone https://github.com/ChenFangfc/OhMyTesla && cd OhMyTesla
./omt up
```

第一次运行会照 `.env.example` 生成 `.env`，填上随机的加密密钥、数据库密码和门户密码，
并把门户密码打印出来（用户名固定 `ohmytesla`）。脚本会先检查 Docker 有没有开，
等应用真的能访问了才返回，最后打印地址。

> 门户密码不能为空：这个界面能解锁车门、关哨兵、看全部位置历史。忘了就
> `./omt portal-password` 重新生成，再 `./omt restart`。

其它命令：

| 命令 | 作用 |
|---|---|
| `./omt up` | 启动（日常就用这个） |
| `./omt down` | 停止，数据保留 |
| `./omt status` | 看各服务状态和数据是否还在流 |
| `./omt logs` | 跟踪日志（`./omt logs teslamate` 看采集端） |
| `./omt restart` | 改完 `.env` 后重启 |
| `./omt update` | 改完代码后重新构建 |
| `./omt backup` | 把数据库导出到 `backups/` |
| `./omt grafana-password` | 改 Grafana 管理员密码（默认是 admin/admin） |

### 2. 连接你的特斯拉账号

打开 **http://localhost:8800**（设了密码就先过认证框：用户名 `ohmytesla`），
没连过账号的话会自动跳到引导页。

特斯拉不允许第三方直接用账号密码登录，需要用小工具走一遍官方登录页拿到两个令牌，任选其一：

- **电脑**：[tesla_auth](https://github.com/adriankumpf/tesla_auth/releases/latest)（Mac、Windows、Linux），解压后打开；
- **iPhone**：App Store 的 [Auth app for Tesla](https://apps.apple.com/us/app/auth-app-for-tesla/id1552058613)。

工具会打开**特斯拉官方登录页**（账号密码只提交给特斯拉，工具和本项目都拿不到），
登录后给你两个令牌，粘到引导页的两个框里，点「连接」。

> macOS 提示"无法验证开发者"时：右键点应用 → 打开，或到 系统设置 → 隐私与安全性 里放行。

token 会加密存进数据库（AES-256-GCM），之后**再也不用管**——会自动续期。

### 3. 确认数据在跑

引导页会自己轮询，读到车之后进入第 2 步「手机提醒」。总览页应该出现你的车
（电量、续航、温度、位置、锁车状态）。

如果卡在"还没有收到车辆数据"，等一两分钟，或去车里唤醒一下车。

> 车在休眠时，总览卡片会标注「这是 X 之前的最后已知状态」——那是从数据库里读的历史值，
> 不是实时数据。车一醒来就会自动刷新。


### 通知渠道怎么选

| 渠道 | 到手机的延迟 | 要装东西吗 | 适合 |
|---|---|---|---|
| **Bark** | 秒级 | iPhone 装 Bark | iPhone 首选：推送显示 OhmyTesla 图标，警报静音时也响 |
| **ntfy** | 秒级 | 装 ntfy App | 安卓首选（iPhone 也能用，但显示 ntfy 的图标） |
| **Telegram** | 秒级 | 多数人已经有 | 不想再装一个 App |
| **邮件** | 几十秒到几分钟 | 不用 | 存档、事后翻查 |
| **浏览器推送** | 秒级 | 不用（点一下开启） | 在电脑前时 |

**哨兵告警别只配邮件。** 邮件到手机的延迟取决于你的邮件 App 多久拉一次，
可能是几分钟——有人在动你的车时，一封迟到的邮件没有意义。
邮件适合存档，实时提醒交给 Bark、ntfy 或 Telegram。

配好一个渠道后，点它旁边的「发送测试」，看手机有没有收到。

#### Bark（iPhone）

1. App Store 安装 [Bark](https://apps.apple.com/app/id1403753865)，打开后允许通知。
2. 复制 Bark 里显示的地址（`https://api.day.app/…`）。
3. 在引导页第 2 步（或 **设置 → 通知 → Bark**）粘贴，点「保存并测试」。

#### 邮件（Gmail）

Gmail 不接受登录密码，必须用「应用专用密码」：

1. 开启两步验证 <https://myaccount.google.com/signinoptions/two-step-verification>
2. 生成应用专用密码 <https://myaccount.google.com/apppasswords>
3. 把那 16 位（去掉空格）填进 `.env` 的 `SMTP_PASS`
4. `./omt restart`

只填了 `SMTP_HOST` 没填密码的话，Security 页会直接告诉你缺哪一项——
不会假装邮件在工作。

#### Telegram

1. 在 Telegram 里找 `@BotFather`，发 `/newbot`，拿到 token
2. 给你的新 bot 发一句话
3. 打开 `https://api.telegram.org/bot<token>/getUpdates`，找到 `chat.id`
4. 填进 `.env` 的 `TELEGRAM_BOT_TOKEN` 和 `TELEGRAM_CHAT_ID`，`./omt restart`

#### 推送里的链接

`.env` 的 `PUBLIC_URL` 决定通知里的链接指向哪。填成手机能访问到的地址
（局域网 IP 或反代域名），否则链接在手机上点不开。

### 4. 配置通知和电价（http://localhost:8800/settings）

- **手机推送**：点「开启推送」。
  - 电脑上直接可用；
  - 手机上要收推送，需要 HTTPS 或 `localhost` 访问（浏览器硬性要求）。
    暂时用不了就用 **Bark**（iPhone）或 **ntfy**（安卓），不受这个限制。
- **电价方案**：填你的电费单价。家充有峰谷电价就选「峰谷分时」，
  按你当地的时段填（默认给了 谷 22:00-08:00 / 平 08:00-17:00 / 峰 17:00-22:00 的模板）。
  保存后点「重新核算全部充电费用」——所有历史充电立刻有钱了。
- **安全**：`OHMYTESLA_PASSWORD` 应该在第 1 步就设好了（车辆控制页能解锁你的车）。
  注意它**只保护 8800**；Grafana 用 `./omt grafana-password` 单独设，
  TeslaMate 的 4000 端口自身不支持认证，只能靠不暴露来保护。

## 日常怎么用

### 看车况
**总览页**（http://localhost:8800）——实时电量、续航、车内外温度、胎压、位置、锁车/哨兵状态，自动刷新。

### 看行车记录仪

**方式 A：U 盘插电脑（最方便，推荐）**

1. 把行车记录仪 U 盘插到你**看网页的这台电脑**上；
2. 打开「行车记录仪 → 🔌 U 盘直读」；
3. 点选择 U 盘里的 `TeslaCam` 文件夹（或整个 U 盘），也可以直接把文件夹拖进页面；
4. 事件列表出来后点任意一个 —— 多机位同步播放，画面上实时显示车速、档位、方向盘、
   油门刹车、Autopilot 状态（这些来自视频内嵌数据），以及电量、功率（来自 TeslaMate）。

   **视频不会上传**，全在你电脑本地播放。

5. 想把某个事件**合成导出成一个 mp4**（带数据条、发朋友圈/交警看那种），
   点右边「导入此事件」传到服务器 → 跳到服务器播放器 → 选布局 → 开始合成 → 下载。

**方式 B：服务器目录（适合 NAS / 树莓派自动同步）**

把 `TeslaCam` 文件夹拷进项目的 `data/teslacam/`（或用 [teslausb](https://github.com/marcone/teslausb) 让树莓派自动通过 Wi-Fi 同步到这里），
然后「行车记录仪」页点「重新扫描」。这种方式下**新的哨兵录像出现时会自动推送告警并附现场缩略图**。

### 收哨兵告警
不用做任何事，自动的。两类：

- **普通触发**（有人靠近、哨兵屏幕亮起开始录像）→ 推送「👀 哨兵触发：检测到车旁有人」；
- **入侵级**（车门/车窗/前后备箱被打开、车辆被解锁、无人状态下车辆移动）→ 严重告警，不受静默时段限制。

消息里带地点、电量和地图链接（高德 + Google）。

**关于漏报**：普通触发靠 TeslaMate 每 30 秒一次的轮询推断（这个间隔是 TeslaMate 写死的，改不了），
所以只持续十几秒的短事件有可能抓不到。想要秒级、不漏报，需要接入
[Fleet Telemetry](FLEET-TELEMETRY.md)（门槛较高：Tesla 开发者账号 + 公网域名 + 证书）。
入侵级信号不受此限制，判定可靠。

**防止被轰炸**：连续活动自动合并成一次会话，只在首次触发、持续 90 秒、以及升级为入侵时各推一次。
在「哨兵告警」页还能**按地点**设策略——自家车位设成「只记录不推送」，公司车库设成「仅持续触发才推」，
陌生地点保持全推。入侵级告警永远不受策略影响。

「哨兵告警」页有完整的活动记录（时间/级别/持续时长/活动次数/地点/数据来源）和规则开关。

### 看数据
- **数据洞察页**：电池健康与衰减、充电统计与花费、能耗-气温曲线、胎压趋势、车辆记录（最高速/最长行程等）、固件更新史；
- **行程页**：行程列表 + 轨迹地图，点某段行程还能直接看**那段路的行车记录仪录像**；
- 更细的长尾面板在 Grafana（http://localhost:3000，端口见 GRAFANA_PORT，用户名 `admin`，
  密码是 `./omt up` 自动生成写进 `.env` 的那个，忘了用 `./omt grafana-password` 重设）。

### 控制车辆
**控制页**——锁车、空调与座椅、充电起停与上限、车窗、前后备箱、充电口、哨兵、鸣笛闪灯；
Cybertruck 另有货箱卷帘、车外插座、对外供电、灯条、悬架。**概览页**的 3D 车上可以直接点车门和盖子。

2021 年以后的车（含全部 Cybertruck）只认签名指令：先在 **设置 → 车辆指令** 走完一次性的
6 步（见 [COMMANDS.md](COMMANDS.md)）。2020 年及以前的 Model S/X 不需要这一步。

车在休眠时点「唤醒」等十几秒再操作。解锁、开备箱、关哨兵等敏感操作需二次确认。

## 想让哨兵告警不漏报（可选升级）

零配置层靠 TeslaMate 每 30 秒一次的轮询推断，短事件可能漏。要秒级不漏，需要官方实时遥测流。

**自建服务器需要公网 IP + 证书，多数人做不到。但可以用托管中转代劳**——
车辆把数据推给中转商，本机主动向外拉一条长连接消费，家里不用开任何入站端口
（SentryPro 那类 App 对用户零门槛，正是因为厂商替你托管了那台服务器）：

```bash
# .env
FLEET_BRIDGE_ENABLED=true
FLEET_BRIDGE_PROVIDER=teslemetry
FLEET_BRIDGE_TOKEN=你的token
```

重启后到**设置页**点「让中转商开始推送 SentryMode 字段」——光填 token 不够，
中转商默认不推这个字段。设置页会显示每辆车的连接状态和收到的事件数。

详见 [FLEET-TELEMETRY.md](FLEET-TELEMETRY.md)（含各中转商对比、国内可用性说明）。

## 采集中断会主动告警

对安防功能来说，最危险的失败不是崩溃，而是**安静地不工作**——页面一切正常，
但告警管道已经死了，你可能一周收不到推送还以为车位很太平。

所以超过 30 分钟收不到车辆数据时，会推一条严重告警，并且打开任何页面顶部都有红色横幅。
阈值可用 `DATA_STALE_SECONDS` 调整。

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 总览页没有车 | 还没在引导页连接账号，或车在深度休眠 |
| 视频在网页里放不出来 | 新固件是 HEVC 编码，Chrome 需要系统硬解。会自动转码预览；也可用 Safari，或直接合成导出（输出 H.264） |
| 视频文件打不开/乱码 | 2026.20+ 固件默认加密录像，去车机 控制 → 安全 → 行车记录仪加密 关掉 |
| 充电费用是 0 或空 | 去设置页配电价方案，然后点「重新核算」 |
| 手机收不到 Web Push | 浏览器要求 HTTPS/localhost。先用 ntfy 或 Telegram |
| 车辆控制说没有 token | TeslaMate 未登录，或提示需要「签名指令」（2021+ 车型，见 [COMMANDS.md](COMMANDS.md)） |
| 想换端口 | 改 `.env` 里的 `*_PORT`，再 `./omt restart` |
| 停止 / 重启 | `./omt down` / `./omt up` |
| 看日志排查 | `docker compose logs -f ohmytesla` |
